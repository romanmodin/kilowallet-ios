# Kilowallet iPhone 1.0 RC2: service privacy notes
Source: operator answers supplied November 2, 2026. Scope: TestFlight preparation. This is not a submitted Apple privacy label.

- Bridge (bridge.kilombino.com, Kilombino): uses onion when app Tor is already running; otherwise HTTPS through Cloudflare, which sees the client IP. The bridge keeps IPs in memory for rate limiting until one hour of inactivity; no IP is logged to disk. Onion requests expose no client IP to the bridge. Quote hash, amount and expiry persist until expiry plus one minute; proof retrieval token lasts one hour; re-quote guard lasts about eleven minutes per hash. The node retains a swap journal indefinitely: payment hash, destination invoice (including recipient node ID), amounts, preimage and state. Operator monitoring retains hashes and states; alerts include amount and truncated hash. No account or payer node ID is received. This does not imply the destination invoice is anonymous.
- Watchtower (Kilombino): onion only. Per-session public key distinct from node identity, encrypted justice blobs and 16-byte breach hints. Decryption requires the matching broadcast breach transaction. No invoices or payment hashes. Session data retained until client deletes session after its channels close. Ordinary rotated info-level LND logs.
- Default Ark server (ark.paperclippool.xyz): Paperclip Holdings LLC, a separate operator. According to the supplied description of its notice, it may retain IP logs, public keys, VTXO IDs, invoices, payment hashes, amounts and recovery data. Retention varies; signing and recovery journals may be long-lived. Notice: https://pool.paperclippool.xyz/privacy ; terms: https://pool.paperclippool.xyz/terms ; contact: contact@paperclippool.xyz. Verify published notice before public submission.
- Kilojoin over Tor: operator identifies this as a next-candidate feature. Do not advertise it for RC2. Verify the next tagged source and build before changing that claim.
